### Para Iniciantes

1. Leia [GETTING_STARTED.md](./GETTING_STARTED.md)
2. Experimente os prompts da seção "Casos de Uso"
3. Customize para seu caso específico

### Para Avançados

1. Explore `02-frameworks/` para soluções complexas
2. Combine técnicas para máxima eficiência

### Para Desenvolvedores

```python
# Exemplo: Usar prompt estruturado
from prompts_library import load_prompt

prompt = load_prompt('02-frameworks/crewai-setup.md')
response = ai.complete(prompt, variables={
    'task': 'seu_objetivo',
    'context': 'seu_contexto'
})
```
